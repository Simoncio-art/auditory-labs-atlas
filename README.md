# Auditory Atlas — Global Map & Connected-Labs Network

Interactive, offline-capable world map, Connected-Papers-style collaboration & bibliographic similarity graph, and searchable directory of **178 verified auditory neuroscience laboratories** across **29 countries** and **28 US states**.

- **Live Web App:** https://simoncio-art.github.io/auditory-labs-atlas/
- **Dataset Snapshot (`2026-11-17`):** 178 labs (117 established centers + 61 specialized/emerging groups), 457 verified coauthorship pairs, and 700 bibliographic/topic similarity bridges computed over 13,150 publications (2014–2026) verified via **OpenAlex**, **Europe PMC**, and **ORCID**.
- **Bilingual (`EN / ES`) & Deep Links:** Automatically selects English or Spanish from browser language (`?lang=en|es` or header toggle) and supports direct shareable links using `?lab=<id>`, `?view=map|network|directory`, `?region=world|usa|canada|uk|europe|latam|apac`, and `?theme=light|dark`.
- **Note on "ABR + MRI + Aging Match (%)":** This index strictly reflects thematic keyword overlap with auditory brainstem/ABR, neuroimaging/MRI, and aging/tinnitus — **not** a measure of lab quality or scientific prestige.
- **Privacy:** Shortlists, theme/language preferences, and personal application notes are stored strictly locally in your browser (`localStorage`).
