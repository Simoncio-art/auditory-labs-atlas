# Auditory Atlas — Global Map & Connected-Labs Network

Interactive offline-capable world map, Connected-Papers-style citation/coauthorship network, and searchable directory of **178 auditory neuroscience laboratories** across **29 countries** and **28 US states**.

- **Web preview:** deployed via GitHub Pages from `index.html`.
- **Privacy note:** Personal shortlists and application notes are stored strictly locally in each user's browser (`localStorage`).
